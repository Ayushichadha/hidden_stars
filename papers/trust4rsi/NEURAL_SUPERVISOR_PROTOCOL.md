# Frozen neural-supervisor study — November 16, 2026

Question: does pre-decision state improve downstream local-versus-broad search
selection beyond checkpoint number? This is a single-decision evaluation on
checkpoints generated by local search. It does not establish performance of a
sequential deployed controller, HRM latent goals, or cross-domain transfer.

Before results: 80 training, 20 validation, 40 test trajectories, each with three
checkpoints (30/90/150 consumed evaluations), all on 26-circle packing. Disjoint
seed ranges and feature list are recorded in the run manifest. Test collection
starts only after models are selected on validation and written to disk.
Each branch uses 60 action evaluations followed by 60 local-continuation
evaluations. Random streams and checkpoint incumbents are paired.

Inputs: checkpoint, current score, preceding local-window gain, radius standard
deviation/minimum/maximum, occupied area, and center spread. No future outcome
is used as an input. Features are normalized using training data only.
Target: broad-minus-local final sum of radii. Predict positive advantage to
choose broad; otherwise choose local.

Comparators: checkpoint-only mean advantage; state-aware ridge regression;
8–16–1 tanh neural regressor (161 parameters), ensemble of three fixed training
initializations. Ridge penalties and neural weight decays: 0.01, 0.1, 1.
Neural training: AdamW, learning rate 0.01, 600 epochs. Validation selects the
candidate maximizing realized downstream score, with fixed candidate order for
ties. The ensemble uses more fitting compute than ridge; this is reported, not
an equal-training-compute claim. Training and validation need 600 branch labels;
test adds 240 branch labels. All collection costs must be reported separately
from policy deployment costs.

Primary comparison: neural minus checkpoint-only score on test, averaging the
three decisions within each trajectory, bootstrap 10,000 trajectory resamples
for a descriptive 95% interval. Secondary: local, always-broad, ridge, and a
stagnation rule. Oracle is hindsight opportunity only. Secondary intervals are
exploratory and uncorrected. No outcome-driven prompt/model/search-space changes
are permitted within this run. The two earlier development studies do not enter
training or test.

Command:
`OPENBLAS_NUM_THREADS=1 python -m scripts.run_math_supervisor_study --workers 4 --output outputs/neural-supervisor-20261116`

Raw data, checkpoints, fitted weights, and report stay under ignored outputs.
No GPU or API expenditure is needed for this small supervised study.

## Completed result

All 140 trajectories completed: 240 training decisions, 60 validation decisions,
120 test decisions. All 420 archived checkpoint geometries and finite features
were independently checked. Seed sets are disjoint. Data collection used 121,800
objective evaluations, including paired branches and checkpoint generation.
No Meta or Modal expenditure was incurred.

| Policy | Test mean final radius sum | Broad decisions / 120 |
|---|---:|---:|

Primary neural-minus-clock difference: +0.001146, trajectory-bootstrap 95%
interval [-0.000263, +0.002800]. The primary comparison is inconclusive.
Neural-minus-local: -0.000333 [-0.001957, +0.001253].
Neural-minus-ridge: -0.000366 [-0.001510, +0.000804].
Secondary ridge-minus-clock: +0.001512 [+0.000468, +0.002675].
Ridge-minus-local: +0.000033 [-0.001360, +0.001513].
Thus beating a checkpoint predictor does not establish improvement over a strong
fixed action. No neural-supervisor superiority is supported by this run.

Validation selected penalties 0.01 (clock), 0.1 (ridge), and 0.01 (neural).
These were saved before test collection. Three neural training initializations
are an ensemble, not three independent experimental replications.

NumPy emitted matmul warnings during ridge fitting/prediction. All frozen
coefficients were finite, independently agreed with an einsum calculation,
and every ridge decision in every split matched that alternative exactly.
Subsequent code uses einsum and explicitly checks coefficient finiteness;
the original run source hash remains in its manifest. The saved models were
not refitted after inspecting test results.

Interpretation and next research decision: preserve this as a falsifiable test
of the controller claim. The action-value gap is sometimes real but the current
features and supervisor have not converted it into a reliable gain over local
search. Before enlarging the model, examine training-data uncertainty and
whether repeated branch rollouts yield stable action preferences. Any ensuing
feature/model revision must use a new evaluation set. Full sequential policy
performance remains unmeasured; this table must not be presented as that result.
